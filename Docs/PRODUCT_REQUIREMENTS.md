# 产品目标与要求

版本 v1.1 · 2026-11-01。本文是待实现要求，不代表已有能力。

## 目标
开发本地原生 macOS 截图工具，面向浏览器、聊天客户端和原生应用中的单个垂直内容区域。目标是快速取得清晰、连续、可预览、可保存的长图，并在不确定时保留结果、解释失败。典型场景：网页文章/长表格、飞书/微信的非敏感测试内容、原生列表/设置/文档；普通区域/窗口截图共用入口。

## 首轮范围
- F01 普通区域/窗口截图：预览、PNG 保存、复制。
- F02 单个垂直区域手动滚动截图：开始后交还目标 App 焦点。
- F03 实时长度/预览反馈；暂停、继续、完成、取消；HUD 不入图、不持续抢焦点。
- F04 无可靠重叠时暂停有效边界，提示回滚补采，保留已验证内容。
- F05 保留合法重复行；不能因高相似、同分排序或去重删行；固定栏遮挡不能静默漏行。
- F06 有界自动滚动：仅在验证过的目标上推进；停止、超时、回手动；不把控制失效伪装成到底。
- F07 适合窗口/100% 预览、基础裁剪、显示完整/局部状态。
- F08 PNG 保存、可行时整图复制、Finder 定位；超预算有序分片并明确说明。
- F09 屏幕录制权限可检查；自动控制权限按需；拒绝/撤销/目标消失/尺寸变化有反馈。
- F10 稳定 Bundle ID、菜单栏入口、可配置快捷键、简洁中文 UI、真实 .app。

F06 在手动闭环后实现，但不能跳过。最低自动证据为受控原生窗口和可用浏览器各完成真实多视口捕获；未完成须明确标记，不宣传完整 V1。即便自动受阻，也交付可用手动版本。

## 交互
普通截图：菜单栏/快捷键→区域或窗口→确认→采集→预览→保存/复制。手动滚动：框选可见正文；提示用户把鼠标放入区域并缓慢滚动；默认从当前画面向下，不自动回顶；非激活 HUD 显示状态/停止；仅通过配准和覆盖验证的帧增加长度；缺少重叠暂停并提示回滚；用户结束只表示本次范围结束，不表示文档到底。自动滚动：每步输入前检查目标，输入后以真实画面验证运动；焦点离开、目标变化、缺少重叠、动画或几何变化立即停止；用户随时接管；默认不移动光标。

结果明确区分连续采集、主动结束、局部结果、未确认尾部；内部缺口不能伪装完整；保存失败保留结果可重试；剪贴板放不下整图时不能只复制第一片却报全部成功。

## 正确性
范围正确；每段新增内容有可解释重叠；相同内容可在不同位置合法重复；无唯一位移时暂停；图像清晰，不静默降质；动态长图不声称是同一瞬间快照；结束原因区分用户结束、可能到底、资源上限、无法配准、环境变化、取消。

## 延期
OCR/文字重建/VCP、云服务/同步/账户、录屏/GIF、团队协作、复杂标注、二维全景/多滚动区、无限长度列表、网站专用 DOM 规则、App Store/付费/正式公证发行。

## 平台与身份
Swift 6、SwiftUI + AppKit、ScreenCaptureKit；最低 macOS 15 作为初始目标，S0 核对实际 SDK。Apple Silicon 优先；Intel 单独记录。应用名 ScrollCapture，仓库 yoCruzer/ScrollCapture，初始 Bundle ID com.yocruzer.ScrollCapture，首次授权后保持稳定。默认离线本地处理。公开仓库不附加项目许可证；引入依赖先审许可证。
