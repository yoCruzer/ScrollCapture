# 验收规范

本文定义方法，不代表 App 已通过。

## 证据层级
- L1 确定性算法回放：固定帧/种子/真值；证明配准、覆盖、恢复；不能证明权限/真实采集。
- L2 受控窗口：真实渲染/滚动与事件驱动变化；不能替代任意原生 App。
- L3 真实 ScreenCaptureKit：生产 App 采集、权限、HUD、坐标、导出链路。
- L4 真实应用人工验收：明确 App 版本和页面类型，形成 Owner 人工成功基线。

测试宿主权限不能替代实际 ScrollCapture Bundle ID 的 TCC 权限。CI、回放、真实 GUI、人工使用分别记录。

## 核心算法验收
A01 唯一纹理多段滚动：逐行/逐像素比对总尺寸、首尾和覆盖。
A02 合法重复行/气泡：保留不同位置重复，不重复追加同一覆盖。
A03 相邻行同分：至少 20 个接缝无系统性 ±1px 漂移；无唯一解暂停。
A04 真实 ±1px/分数位移：保留真正纠偏能力，绝对累计边界取整。
A05 纯色/周期纹理/无重叠：不猜位移、不硬拼。
A06 固定栏/遮挡：匹配干扰与正文实际覆盖分别验证。
A07 快滚丢重叠后回滚找锚点：保留已确认结果，恢复后连续。
A08 逆滚经过旧内容再向下：不负向追加、不重复。
A09 重复采集帧、静止帧、排队延迟：不重复提交，旧帧不污染新会话。
A10 首张正式帧后触发布局变化：验证变化时序，暂停或按声明契约处理。

## 原生与交互
N01 区域/窗口/长图真实采集，点像素映射正确。N02 resize/scale 变化暂停或安全重建。N03 无进展与到底区分。N04 HUD 不抢焦点且不入图。N05 目标关闭/被遮挡不误采其他窗口。N06 取消后不再提交/输入。N07 多会话和长图资源有界。N08 PNG/分片/剪贴板正确，失败可重试。N09 权限拒绝/撤销可恢复。N10 菜单栏、快捷键、预览、裁剪、保存完整。

## 自动滚动
B01 受控原生窗口真实多视口自动采集；B02 失焦/目标关闭/尺寸变化立即停止；B03 可用浏览器自动多视口并可切回手动。F06 至少 B01+B03 通过；否则明确未完成。

## Owner 人工检查
用非敏感测试内容在 Chrome/Safari、飞书、微信（可用时）检查整图首尾、中间、重复行、固定栏、HUD 焦点、恢复、保存/复制和重启。未安装/不可用记 Not tested，不为测试改变账号环境。真实截图不进入公开仓库。
