# 新手体验检查与改进

2026-11-15 · 基线 fde860f / 实际旧版 App 303c331。检查方式：实际首屏与权限失败界面、生产状态流阅读、独立只读审查；后续构建与 GUI 结果见 STATUS 和 DEVELOPMENT_LOG。设计判断不是用户调研结论。

## 已实现

| 问题 | 新手受到的影响 | 本轮处理 |
|---|---|---|
| 首屏同时展示采集、导出、裁剪、快捷键与验收工具 | 大量禁用按钮，难以知道第一步 | 三步侧栏：选择窗口、选择范围、检查与保存；只显示当前步骤的操作 |
| 空白预览区没有操作入口，按钮视觉权重相同 | 容易停在空窗口 | 空状态直接提供选择入口；独立预览画布、明确主按钮、统一间距与系统语义色 |
| 开发测试按钮占据标题栏 | 容易误触验收并覆盖当前内容 | 收入“设置与工具 → 开发与验收工具”；存在截图时禁用 |
| “获取画面 / 区域截图”含义不清 | 不知道是否已经完成截图 | 改为“预览并选择范围”“截取所选区域 / 整个窗口”“开始滚动截图” |
| 框选时可以直接保存整窗，100% 模式又会隐藏框选 | 选中范围与实际导出容易不一致 | 选区阶段必须确认单张或开始滚动后才进入结果导出；模型层拒绝未确认选区的保存/复制；框选不受结果缩放影响 |
| 整窗直接用于滚动采集 | 固定导航栏干扰且新手不知道如何恢复 | 滚动按钮要求先框选正文；选区之外变暗、双层边框；即时显示像素尺寸 |
| 暂停、恢复、技术术语提示不够明确 | 不知道应该继续向下还是回滚 | 区分主动暂停与异常暂停；提示回到已截内容后继续；用“次拼接”代替接缝术语 |
| HUD 的所有操作平铺、取消紧邻完成 | 易误丢截图；长错误可能挤掉按钮 | “完成并预览”为主按钮；其他操作收入菜单；放弃需确认；说明滚动、底部操作固定 |
| 自动停止原因被静止帧提示覆盖 | 看不出自动已经停止，容易误认为成功 | 独立持久提示；所有停止路径更新运行状态；界面标注“实验功能 / 未通过实际自动验收” |
| 导出前不清楚是否需要分片 | 复制后才发现整图过大 | 根据实际最终高度展示“保存全部分片”，提前说明预览只含首片并禁用整图复制 |
| 裁剪输入没有说明和合法性反馈 | 数值错误只报无法读取画面 | 收入折叠区；顶部/底部独立标签、像素单位、禁用无效提交；模型保留结果并解释错误 |
| 权限失败混同其他窗口读取错误 | 不知道如何恢复，也可能被误导授权 | 权限失败面板、系统设置直达；权限存在时保留实际错误；明确手动不需要辅助功能 |
| 新建或换目标的状态不清楚 | 旧预览可能被误当成新目标 | 新建已有截图需确认，换目标清除旧预览，旧清理回调不覆盖新提示 |
| 最终显示尺寸沿用帧回调计数 | 完成与最后一次提交竞争时可能显示旧尺寸 | finish 从封存 session 的实际尺寸更新最终高度 |

## 保留的后续改进

- F06 实际自动滚动仍未通过；本轮只改善入口和反馈，没有解除目标保护或宣称修好了自动控制。
- 选区目前需要鼠标拖动；键盘调整、边缘拖拽手柄、选区记忆尚未实现。
- 裁剪暂不提供撤销或交互式裁剪预览；应用前有数值检查，原始导出请先保存。
- 超长图仍只预览首片，没有分片导航；已明确展示这一限制。
- 完整 VoiceOver 操作、放大字体、深色模式、不同显示器比例需要单独验证；可访问标签不等于完成这些验收。
- 内置字体 oracle 已知失败仍保留，移入开发工具不改变其验收结论。

## 本轮集中检查路线

选择窗口 → 预览 → 拖选正文 → 单张确认 → 适合窗口/100% → 裁剪 → 保存/复制 → 新建取消确认；再用非敏感合成窗口验证滚动 → 暂停/继续 → 完成 → 结果尺寸/保存。检查 HUD 长消息时按钮可达，自动停止提示不会被新帧状态覆盖。任何新二进制权限拒绝应保留 AWAITING_PERMISSION，不复用旧版 GUI 成功冒充新版证据。
