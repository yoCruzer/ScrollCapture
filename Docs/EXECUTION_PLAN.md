# Codex 连续执行计划

启动目标 v1.1 · 2026-11-01。单个 /goal 按 S0–S4 连续推进，阶段完成即提交、普通推送、更新 Draft PR 并继续。E0–E3/R01–R10 是实验索引，不是额外串行阶段；按风险选用，不先跑完研究才开工。

## S0 工程与真实采集
核对远端/分支/工作区/Xcode/Swift/SDK；隔离 worktree；建立可运行 App bundle、稳定 Bundle ID、签名与权限身份；菜单栏、权限重检、目标窗口/区域选择、一张真实截图；合成受控滚动宿主和最小离线真值回放；记录真实 build/test/run 命令。出口：实际 App 可启动并保存目标截图，权限归属清楚。提交并独立 review。

## S1 手动端到端
连续 ScreenCaptureKit 采集；真实帧时间/尺寸/scale；位移候选＋独立重叠验证；只追加新增覆盖；开始/暂停/继续/完成/取消；非激活 HUD；交还焦点；预览、100%、PNG、复制、Finder；普通区域/窗口共用导出。受控原生窗口和浏览器真实滚动多视口，至少三个接缝、独立参考逐行/像素核对首尾。

## S2 正确性、恢复、资源
重复/同分、真实微位移、分数位移、固定栏/遮挡、快滚丢帧、逆滚重定位、resize/scale/目标消失/权限撤销、旧 generation 回调、可信前缀、内部缺口、分片输出、导出失败/取消清理。按实测定内存/磁盘/像素预算。无法唯一定位的场景应暂停，不无限调参。

## S3 有界自动与体验
在手动核心上增加 ScrollDriver：每次发送一步、观察、验证、提交后再继续；步长/等待/时长/次数/无进展上限；焦点/目标/几何变化立刻停止；支持暂停、停止、切回手动。分别区分到底、输入未生效、等待加载、低信息。受控原生窗口与浏览器均完成真实自动多视口采集才算 F06 最低通过。失败则明确标记 F06 未完成，仍交付手动候选。

## S4 独立审查与交付
独立 reviewer 只读检查正确性、并发、恢复、资源、权限、隐私、UX；修 P0/P1 和阻断核心的 P2。对本次声称支持范围集中跑一次必要回归，失败定向补验。实际构建并启动交付 App。核心真实采集/GUI/多视口证据缺失则保持 BLOCKED/AWAITING_PERMISSION，交付候选与最少补验步骤；不提前 READY。额外真实应用兼容性/Owner 体验可集中后验。普通推送，保留 Draft PR，不合并/发布。

## 测试成本
算法改动跑对应真值和失败回放；采集/权限/坐标/HUD 改动跑真实 App 定向验证；导出/资源/取消做错误注入；文档/UI 文案不重复图像矩阵。最终一次相关完整回归，之后只补受影响项。
